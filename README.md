# AI Productivity Dashboard

A modern dark-themed AI productivity dashboard built with HTML and CSS.

## Live Demo

https://parivrax.github.io/AI-Productivity-Dashboard/

## Overview

This project is a desktop dashboard UI focused on modern layout design, neon visual effects, and clean card-based sections.
It was built as part of my front-end development practice to improve my skills in HTML structure, CSS Grid, visual hierarchy, and component-based styling.

## Features

- Dark modern dashboard interface
- Bento-style grid layout
- Neon gradient accents
- Glassmorphism-inspired cards
- Custom visual assets and icons
- Organized HTML and CSS structure

## Tech Stack

- HTML5
- CSS3
- CSS Grid
- Flexbox
